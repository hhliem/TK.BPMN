## 2. Kết Quả Triển Khai Chi Tiết Theo Sprint Backlog

### 2.1. Phân Hệ Động Cơ Quy Trình & Trình Ký (WorkflowEngine - Schema `[workflow]`)
- [x] **Domain (`EnterpriseBpm.Workflow.Domain`):**
  - Thực thể nghiệp vụ: `WorkflowSubmission` (ISoftDeletable, IAuditable), `ApprovalTask`, `ApprovalHistory` (Immutable).
  - Enums: `WorkflowStatus`, `WorkflowPriority`, `ApprovalTaskStatus`, `ApprovalDecision`.
  - Nghiệp vụ ngoại lệ: `TaskAlreadyProcessedException`, `WorkflowSubmissionNotFoundException`, `ApprovalTaskNotFoundException`, `DistributedLockAcquisitionException`.
  - Dịch vụ bảo mật Chữ ký số: `DigitalSignatureService` tự động tính mã băm SHA-256:
    $$\text{DigitalSignatureHash} = \text{SHA256}(\text{WorkflowInstanceId} + \text{StepOrder} + \text{ActorUserId} + \text{Decision} + \text{ActionTimestamp} + \text{Salt})$$
- [x] **Application (`EnterpriseBpm.Workflow.Application`):**
  - Public Contracts: `IWorkflowSubmissionService`, `IApprovalTaskService`, `IApprovalTaskDispatcher`, `IApprovalHistoryService`, `IWorkflowRuntimeEngine`, `IDistributedLockService`.
  - Integration Events: `TaskAssignedEvent`, `TaskSlaBreachedEvent`, `WorkflowApprovedEvent`, `WorkflowRejectedEvent`, `WorkflowCancelledEvent`, `WorkflowCompletedEvent`.
  - Event Handler: `EmployeeDeactivatedWorkflowHandler` tự động điều chuyển tác vụ sang cấp quản lý khi nhân sự thôi việc.
- [x] **Infrastructure (`EnterpriseBpm.Workflow.Infrastructure`):**
  - `WorkflowDbContext`: Schema riêng biệt `[workflow]`, Covering Indexes, Soft delete query filter.
  - Redis RedLock: `RedisDistributedLockService` khóa `lock:approval_task:{taskId}` TTL 10 giây, chặn triệt để click đúp / duplicate submission.
  - Phân giải người duyệt đa cấp: `ApprovalTaskDispatcher` tích hợp với `IOrgHierarchyService` và `IDelegationResolver` của module `Org`.
  - Atomic State Synchronization: Bọc Task, History, Bookmark Resume và MediatR Events trong Database Transaction duy nhất (`IUnitOfWork`).
  - Worker nền quét SLA: `SlaEscalationBackgroundWorker` phát hiện nhiệm vụ quá hạn, kích hoạt leo thang và phát `TaskSlaBreachedEvent`.
- [x] **Presentation (`EnterpriseBpm.Workflow.Presentation`):**
  - `WorkflowSubmissionsController`: `POST /api/workflows/submissions`, `GET /{id}`, `POST /{id}/cancel`.
  - `ApprovalTasksController`: `GET /api/workflows/tasks/pending`, `POST /{id}/decision`.
  - `ApprovalHistoryController`: `GET /api/workflows/history/{instanceId}`.

### 2.2. Phân Hệ Quản Lý Tài Liệu & OneDrive (DocumentManagement - Schema `[document]`)
- [x] **Domain (`EnterpriseBpm.Document.Domain`):**
  - Thực thể: `WorkflowAttachment` (ISoftDeletable), `DocumentTemplate` (IAuditable), `GeneratedDocument`.
  - Enums: `TemplateFormat` (`Docx`, `Pdf`, `Xlsx`).
  - Điểm kiểm soát an toàn tập tin (`FileValidationRules`):
    * Whitelist định dạng: `.pdf`, `.docx`, `.xlsx`, `.pptx`, `.jpg`, `.jpeg`, `.png`.
    * Giới hạn dung lượng: Tối đa $25\text{ MB}$ ($26,214,400\text{ bytes}$).
    * Chặn tệp tin rỗng 0 byte hoặc phần mở rộng nguy hiểm (.exe, .sh, .bat).
- [x] **Application (`EnterpriseBpm.Document.Application`):**
  - Public Contracts: `IDocumentStorageService`, `IDocumentTemplateService`, `IDocumentGeneratorService`, `IExternalStorageClient`.
  - Integration Event Handlers:
    * `AutoGenerateDocumentOnApprovalHandler`: Lắng nghe `WorkflowApprovedEvent` tự động sinh văn bản quyết định từ template.
    * `HandleDocumentOnWorkflowCancelledHandler`: Lắng nghe `WorkflowCancelledEvent` đánh dấu xóa mềm các file đính kèm liên quan.
- [x] **Infrastructure (`EnterpriseBpm.Document.Infrastructure`):**
  - `DocumentDbContext`: Schema riêng biệt `[document]`, Unique index trên `TemplateKey`, Indexes trên `WorkflowInstanceId`.
  - Nguyên tắc **Zero-Binary-in-DB**: `ExternalStorageClient` truyền stream trực tiếp theo cây phân cấp `/BPMN_Enterprise_Storage/{Year}/{Month}/{WorkflowInstanceId}/`, SQL Server chỉ lưu metadata nhẹ.
  - Bảo mật truy cập: Sinh **Time-limited Signed URLs** có thời hạn hết hạn trong 15 phút, ngăn chặn truy cập công khai trái phép.
  - Sinh văn bản template: `DocumentGeneratorService` làm sạch placeholder chống tiêm mã độc VBA, tính toán mã băm SHA-256 ngay lúc sinh để kiểm soát toàn vẹn.
- [x] **Presentation (`EnterpriseBpm.Document.Presentation`):**
  - `WorkflowAttachmentsController`: `POST /api/documents/attachments/upload`, `GET /workflow/{id}`, `GET /{id}/preview-url`, `DELETE /{id}`.
  - `DocumentTemplatesController`: `POST /api/documents/templates`, `GET /api/documents/templates`.
  - `GeneratedDocumentsController`: `POST /api/documents/generated/from-template`, `GET /workflow/{id}`.

### 2.4. Chuẩn Hóa Cấu Hình Redis Server Riêng Biệt & Quản Trị Caching Tập Trung (Host-Managed Distributed Cache)
- [x] **Độc lập hóa Máy chủ Redis (Dedicated Redis Server & Docker):**
  - Hỗ trợ hoàn toàn trỏ tới máy chủ Redis chạy Docker, VM riêng, Remote Linux hoặc Cloud Redis Cluster mà không hardcode địa chỉ.
  - Hỗ trợ cả 2 định dạng: `ConnectionStrings:Redis` và `Redis:ConnectionString` kèm các options: IP/Host, Port tùy biến, Password/Auth, SSL/TLS, Timeout.
  - Hỗ trợ `Redis:InstanceName` (ví dụ `EnterpriseBpm:Dev:`, `EnterpriseBpm:Prod:`) để cô lập namespace cache giữa các môi trường khi dùng chung 1 Redis Server.
- [x] **Quản trị Caching Tập trung theo Clean Architecture:**
  - Chuẩn hóa đăng ký `IDistributedCache` (`Microsoft.Extensions.Caching.StackExchangeRedis`) duy nhất tại tầng Host (`EnterpriseBpm.ApiHost/Program.cs`).
  - Loại bỏ đăng ký trùng lặp/xung đột `AddDistributedMemoryCache` trong `EnterpriseBpm.Workflow.Infrastructure`.
  - Cả 4 module (`AccessGovernance`, `Form`, `Workflow`, `Document`) đều tái sử dụng chung một hạ tầng Distributed Cache thống nhất.
  - Bổ sung log chẩn đoán trạng thái kết nối Redis lúc khởi động ứng dụng (thông báo rõ ràng endpoint đang kết nối hoặc fallback về InMemory).
